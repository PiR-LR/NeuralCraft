# ⚡ NeuralCraft Engine

> **Ingénierie Web Antigravité.**
> Zéro Bloatware. Zéro latence. Des architectures modernes taillées pour la vélocité pure et l'expérience utilisateur temps réel.

NeuralCraft est le portfolio et studio de développement web expert spécialisé dans la conception d'applications web complexes (Next.js, Supabase), de systèmes temps réel (Socket.io, MongoDB) et de sites ultra-performants (Astro).

## 🚀 Philosophie & Stack Technique

Ce projet est construit sur une architecture Edge-First pour garantir un score Lighthouse parfait et un temps de chargement immédiat (< 0.5s).

*   **Framework Core :** [Astro](https://astro.build/) (SSG & View Transitions)
*   **Styling :** [Tailwind CSS](https://tailwindcss.com/) (Atomic Design)
*   **Moteur de Scroll :** [Lenis](https://lenis.studiofreight.com/) (Smooth Scroll & Inertie Physique)
*   **Typographie :** Plus Jakarta Sans (Titres) & Inter (Texte)
*   **UI/UX :** Animations CSS fluides (Hardware Accelerated), Scroll-driven events, SVG interactifs.

## 🧠 Domaines d'Expertise Démontrés

1.  **Moteur Métier & Calculs :** Plateformes sur-mesure (Next.js / Supabase / PostgreSQL).
2.  **Flux Bi-directionnel :** Systèmes et interactions Temps Réel (Socket.io / Node.js / MongoDB).
3.  **Vélocité & Vitrine Premium :** Hubs ultra-fast (Astro / Cloudflare Edge).
